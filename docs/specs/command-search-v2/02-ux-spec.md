# Command Search V2 - UX Spec

## 1) Mental Model

Command Search V2 是一个“桌面版 Spotlight 式命令面板”：

- 它不是“页面内过滤器”，而是“全局入口 + 对象定位器 + 动作启动器”。
- 用户只需要记住一个动作：`⌘K` 打开，输入关键词，回车执行。
- Scope 是“当前工作上下文提示”，不是必须先理解的概念；默认自动推断，用户可随时清除。

## 2) Information Architecture（IA）

### 2.1 信息层级

1. 输入层：搜索输入框 + scope chip（若存在）
2. 主结果层：对象结果（项目/场景/模特）
3. 次结果层：动作结果（新建、导航）
4. 辅助层：最近访问（仅无输入时）

### 2.2 默认焦点规则

1. 打开弹窗：焦点在输入框
2. 结果更新：高亮重置为首项
3. Enter：执行当前高亮项
4. Backspace（输入为空且有 scope）：移除 scope
5. Esc：关闭弹窗并清空查询

### 2.3 Scope 规则

- `global`：默认全局
- `project`：在项目上下文（包含 `/?project=<id>`）时自动进入
- `assets-scenes`：在 `/assets/scenes` 时自动进入
- `assets-models`：在 `/assets/models` 时自动进入

## 3) Affordance（可发现性）

- 顶部 Toolbar 搜索按钮必须明确展示快捷键提示（`⌘K`）。
- 对话框输入区左侧始终显示搜索图标，右侧可见 scope chip（若有）。
- 每条结果必须包含：图标 + 主标题 + 次级信息；高亮态与 hover 态一致。
- 分组标题使用弱化文本，不与结果项争夺视觉权重。

## 4) System Feedback（含恢复路径）

### 4.1 Empty States

1. 首次打开（无输入、无最近）：
   - 文案：`输入关键词搜索项目、场景、模特或操作`
   - 下一步：展示 2-3 个快捷操作（新建项目/新建场景/打开设置）

2. 有输入但无匹配：
   - 文案：`没有找到匹配结果`
   - 下一步：展示可执行建议（`新建项目` / `新建场景`）

3. 当前 scope 无结果：
   - 文案：`当前范围未命中，试试清除范围后全局搜索`
   - 下一步：提供 `清除范围` 按钮

### 4.2 Loading States

1. 打开弹窗首次拉取数据：
   - 结果区显示 skeleton 行（不少于 4 行）
   - 下一步：保持键盘可输入，不阻塞

2. 输入中实时更新：
   - 不显示全屏 loading，仅在分组标题右侧显示轻量“更新中”
   - 下一步：继续输入可中断当前计算

3. 执行跳转动作后：
   - 立即关闭弹窗；目标页负责展示自身 loading
   - 下一步：若目标页失败，提供回到来源页路径

### 4.3 Error States

1. 项目数据加载失败
   - 文案：`项目数据加载失败`
   - 恢复：`重试`（仅重试项目分组）

2. 场景数据加载失败
   - 文案：`场景数据加载失败`
   - 恢复：`重试`

3. 模特数据加载失败
   - 文案：`模特数据加载失败`
   - 恢复：`重试`

4. 最近访问存储不可用
   - 文案：`最近访问暂不可用`
   - 恢复：降级为只显示快捷操作，不阻断搜索主流程

5. 目标实体不存在（已删除）
   - 文案：`目标不存在或已删除`
   - 恢复：跳转到对应列表页并提示刷新

6. 路由跳转失败
   - 文案：`跳转失败，请重试`
   - 恢复：提供 `重试` 和 `复制错误信息`

## 5) Component Detail（与仓库现状对齐）

### 5.1 Sidebar / Toolbar 入口

- 入口位于 AppShell 顶栏，不再在各模块重复放搜索框。
- 按钮点击和快捷键行为必须等价（都调用 `setOpen(true)`）。
- 当搜索弹窗打开时，入口按钮保持静态，不切换成激活态，避免视觉抖动。

### 5.2 Command Search Result Panel

- 分组顺序：
  - 无输入：`最近继续工作` -> `常用操作`
  - 有输入：`最佳匹配` -> `对象结果` -> `动作结果`
- 对象项点击后需“落位”：
  - 项目：`/` + `project=<id>`
  - 场景：`/assets/scenes` + `sceneId=<id>`（或同等可定位参数）
  - 模特：`/assets/models` + `modelId=<id>`

### 5.3 设置页（Search 偏好）

- 新增可选设置（后续版本，可延后实现）：
  - `默认显示最近访问`（开/关）
  - `记住上次 scope`（开/关）
  - `清空最近访问`
- 不引入复杂个性化推荐，仅提供可控偏好项。

## 6) Copy & Microcopy

原则：

- 文案必须给出下一步动作，禁止“未知错误”单句结束。
- 优先使用用户目标导向语言（例如“继续上次工作”而不是“最近记录”）。
- 动作文案统一动词开头：`新建项目`、`打开设置`、`清除范围`、`重试`。

建议文案：

- 搜索占位：`搜索项目、场景、模特或操作...`
- scope 清除提示：`已限定当前范围，按 Backspace 可清除`
- 无结果：`没有找到匹配结果，试试更短关键词`

## 7) A11y 最低要求

- 打开弹窗后焦点必须进入输入框；关闭后焦点回到触发按钮。
- 支持完整键盘路径：`↑/↓` 导航、`Enter` 执行、`Esc` 关闭、`Backspace` 清 scope。
- 每条结果项需有可读文本，不依赖颜色表达状态。
- 结果分组标题与结果项需具备语义结构（屏幕阅读器可区分组与项）。
