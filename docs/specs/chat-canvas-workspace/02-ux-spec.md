# Chat-Canvas Workspace V1：UX Spec

> FEATURE_SLUG: `chat-canvas-workspace`
> 基于：`docs/specs/chat-canvas-workspace/01-feature-spec.md`

## 1. Mental Model

用户把工作台理解为“会话驱动的创意白板”：

1. 左侧选择会话（上下文容器）。
2. 中间整理视觉草案（画布）。
3. 右侧通过自然语言获取下一步建议（动作卡）。

核心心智：系统只“建议”，用户才是“应用者”。

## 2. 信息架构（IA）

- 一级入口：左侧主导航 `工作台`。
- 页面三栏固定：
  - 左栏：会话列表（创建 / 切换 / 删除）
  - 中栏：画布（节点编辑）
  - 右栏：Chat 与动作卡

默认焦点：

1. 首次进入可快速新建会话。
2. 有历史会话时默认打开最近更新会话。
3. 发送消息后输入框自动回焦。

## 3. 交互规则

### 3.1 会话

- 新建会话立即进入编辑态。
- 删除会话二次确认。
- 会话详情（节点、视口）自动持久化。

### 3.2 画布

- 支持拖拽节点、框选、多选、分组、删除。
- 支持平移、滚轮缩放、适配视图。
- Undo/Redo：
  - 记录编辑操作与动作卡应用。
  - 不记录纯视口变化。

### 3.3 Chat + 动作卡

- 发送消息时注入：
  - 当前选中节点
  - `@` 解析出的场景/模特引用
- 助手返回动作卡列表，每张卡片可单独应用。
- 应用中仅锁定当前卡片，不阻断画布其他交互。

## 4. Empty / Loading / Error

### Empty

1. 无会话：展示“新建会话”。
2. 会话有消息无节点：提示从资产或建议开始落第一张卡。

### Loading

1. 会话列表加载：左栏 skeleton。
2. 发送消息：输入区与消息区展示 loading。
3. 应用动作卡：仅卡片进入 loading。

### Error

1. `PROVIDER_REQUIRED`：整页禁用，提供“前往设置”。
2. `REVISION_CONFLICT`：提示刷新，并允许重放本地未提交变更。
3. `INVALID_ACTION_CARD`：保留用户消息并支持重试。
4. `ASSET_NOT_FOUND`：提示引用资产失效，需替换后重试。
5. `INVALID_PAYLOAD`（导入）：明确提示 JSON 结构错误并拒绝写入。

## 5. 关键文案

- 建议模式标识：`建议模式`。
- Chat placeholder：`输入你的创作意图，回车发送（Shift+Enter 换行）`。
- 引用提示：`可用 @场景名 / @模特名`。
- Provider 禁用页：`需要先配置默认 Provider 才能使用 Chat + 画布工作台。`

## 6. 可用性与性能

- 目标：100 节点内保持顺滑编辑体验。
- 最低可用性：
  - 键盘可发送消息
  - Undo/Redo 可达
  - 导入导出可完成闭环

## 7. 验收走查清单

- [ ] 新建会话 → 发消息 → 应用动作卡 → 刷新后状态仍在。
- [ ] 100 节点拖拽、框选、多选、分组、缩放操作可用。
- [ ] 无 Provider 时页面禁用，且可一键前往设置恢复。
- [ ] 导出 JSON 后再导入，消息与画布布局一致。
- [ ] 选中注入与 `@` 引用可同时生效。
